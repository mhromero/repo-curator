# Worker Phase: Editing

Perform only the work in the human-approved edit plan and within Repo Curator's change-authority policy.

Reuse your existing understanding from the inspection phase.

## Rules

- Preserve original behavior unless an approved change explicitly allows otherwise.
- Do not broaden the plan silently.
- Do not refactor for cleanliness.
- Do not invent README claims.
- Preserve relevant existing README information unless it is demonstrably obsolete, duplicated, or incorrect.
- Keep personal, academic, authorship, licensing, and intentionality claims grounded in evidence or human confirmation.
- Do not add Repo Curator state or internal files to the target repository.
- You may run cheap non-destructive sanity checks during editing.

If an unexpected issue requires a new risky change, stop and request approval.

## Completion report

When editing is complete, stop for human review and report:

- files modified;
- files removed;
- whether source code changed;
- deviations from the approved plan;
- sanity checks run and their results;
- unresolved concerns.

Do not declare the repository finished.
